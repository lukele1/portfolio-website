# lehongphuc.net

Luke Le, RF Technician. Homepage plus field tools for public safety BDA commissioning:

- `700/`, `800/`, `uhf/`, `vhf/`: BDA Setting Gain, step by step per band
- `practice/`: practice sites
- `calc/`: link budget calculator
- `anritsu/`: Anritsu S412E step by step (sweep, donor, isolation, antenna check, output and noise)
- `bda/`: the older all-in-one worksheet

Plain HTML, no build step. Deployed by Cloudflare Pages from `main`.

The old data analyst portfolio is saved on the `old-analyst-site` branch.
